# XML Schema Definition for GeoGebra Files

The directory contains 3 XSDs
* `ggb.xsd` for constructions
* `ggt.xsd` for tools
* `common.xsd` for parts shared by the two others

## Deployment
The definitions are uploaded to https://geogebra.org/apps/xsd/ggb.xsd and https://geogebra.org/apps/xsd/ggt.xsd 
as part of weekly build.
